# איך בונים את Wealth Horizon לאנדרואיד

מדריך צעד-אחר-צעד. **ההנחה היא שלא התקנת Android Studio מעולם.**
אם משהו לא ברור — זו אשמת המדריך, לא שלך.

---

## מה הולך לקרות כאן

האפליקציה כתובה ב-React ורצה בדפדפן. **Capacitor** עוטף אותה
ב"קליפה" של אנדרואיד — WebView (דפדפן בלי כפתורים, בתוך אפליקציה) —
ומייצר **APK**: קובץ ההתקנה של אנדרואיד, המקבילה של `.exe` בווינדוס.

הקוד לא נכתב מחדש. אותו קוד בדיוק, בתוך אריזה אחרת.

---

## שלב 1 — התקנת Android Studio

Android Studio היא סביבת הפיתוח של גוגל. אנחנו לא באמת נכתוב בה קוד —
אנחנו צריכים אותה בשביל ה-**SDK** (ערכת הכלים שיודעת להפוך קוד ל-APK).

1. הורד מ-<https://developer.android.com/studio> ובחר Windows/Mac לפי המחשב שלך.
2. הרץ את המתקין ולחץ Next על הכל. ברירות המחדל טובות.
3. בפתיחה הראשונה הוא יציע להוריד רכיבים (~2–3 ג'יגה). **תן לו.**
   זה ה-SDK, בלעדיו אין APK.
4. חכה שיסיים. זה לוקח זמן.

**מה אמור לקרות:** נפתח מסך "Welcome to Android Studio".

---

## שלב 2 — התקנת Java

Capacitor בונה עם **Gradle**, שדורש **JDK 21**.

Android Studio מגיע עם JDK משלו, ולרוב זה מספיק. אם בשלב 5 תקבל שגיאה
על Java, התקן ידנית מ-<https://adoptium.net> (בחר **Temurin 21 LTS**).

בדיקה שזה עבד — פתח טרמינל (ב-Windows: `cmd`) והרץ:

```bash
java -version
```

אתה אמור לראות `21.something`. אם אתה רואה "command not found", Java לא מותקנת.

## שלב 3 — הכנת הפרויקט

בטרמינל, בתוך תיקיית הפרויקט:

```bash
npm install       # מוריד את כל הספריות שהקוד צריך
npm run build     # הופך את קוד ה-React לקבצים סטטיים בתיקיית dist/
npx cap sync      # מעתיק את dist/ אל תוך פרויקט האנדרואיד ומעדכן תוספים
```

> **`npx cap sync` — זו הפקודה שהכי קל לשכוח.**
> בלעדיה האפליקציה על הטלפון תמשיך להראות את **הגרסה הישנה**, גם אחרי
> ש-`npm run build` הצליח. כל שינוי בקוד מחייב `build` ואז `sync`.

---

## שלב 4 — פתיחת הפרויקט ב-Android Studio

```bash
npx cap open android
```

זה פותח את Android Studio על התיקייה הנכונה.

בפתיחה הראשונה הוא ירוץ **Gradle sync** — הורדת ספריות בנייה. זה לוקח
כמה דקות ודורש אינטרנט. חכה שהפס התחתון יסיים ויכתוב
`Gradle sync finished`.

**אם יש שגיאה אדומה:** ברוב המקרים היא אומרת שחסר רכיב SDK, ומציעה
לינק "Install missing platform(s)". לחץ עליו, ואז על "Sync Now".

---

## שלב 5 — בניית ה-APK

בתפריט העליון: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

כשזה נגמר תקפוץ הודעה בפינה עם הקישור **locate**. לחץ עליו — זה יפתח
את התיקייה עם הקובץ.

הנתיב המלא:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

**אפשר גם בלי Android Studio**, ישירות מהטרמינל:

```bash
cd android
./gradlew assembleDebug        # ב-Windows: gradlew.bat assembleDebug
```

התוצאה נוחתת באותו מקום.

## שלב 6 — התקנה על הטלפון

### הדרך הפשוטה — העברת הקובץ

1. חבר את הטלפון למחשב בכבל USB.
2. בטלפון, בחר במצב **"העברת קבצים" / File Transfer** (לא "טעינה בלבד").
3. העתק את `app-debug.apk` לתיקיית ההורדות של הטלפון.
4. בטלפון, פתח את אפליקציית **קבצים**, מצא את ה-APK, ולחץ עליו.
5. אנדרואיד יזהיר: *"לא ניתן להתקין אפליקציות ממקור זה"*. לחץ
   **הגדרות** → הפעל **"אפשר ממקור זה"** → חזור אחורה → **התקן**.

האזהרה הזו תקינה. היא מופיעה לכל אפליקציה שלא הגיעה מ-Google Play.
בנית אותה בעצמך, אז אתה יודע מה יש בה.

### הדרך של מפתחים — התקנה בכבל

דורשת הפעלת **מצב מפתח** בטלפון:

1. הגדרות → אודות הטלפון → לחץ **7 פעמים** על "מספר בניה" (Build number).
   תופיע הודעה "אתה עכשיו מפתח".
2. הגדרות → אפשרויות מפתחים → הפעל **ניפוי באגים ב-USB** (USB debugging).
3. חבר בכבל, אשר את החלון שקופץ בטלפון, והרץ:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

`-r` מחליף התקנה קיימת בלי למחוק את הנתונים שלך.

**מ-Android Studio:** בחר את הטלפון בתפריט המכשירים למעלה ולחץ על
כפתור ה-▶ הירוק. זה בונה, מתקין ומפעיל בפעולה אחת.

## APK לחתימה (release)

ה-APK שבנינו הוא **debug** — גדול יותר, איטי יותר, וחתום במפתח זמני.
לשימוש אישי זה לגמרי בסדר.

אם תרצה גרסת release אמיתית תצטרך **keystore** — קובץ מפתח שחותם על
האפליקציה. **אל תאבד אותו:** בלעדיו לא תוכל להתקין עדכון על גבי
ההתקנה הקיימת, ותצטרך למחוק את האפליקציה — ואיתה את כל הנתונים.

זה לא נדרש כרגע. נעשה את זה כשיהיה צורך.

## תקלות נפוצות

| מה אתה רואה | מה זה אומר | מה לעשות |
|---|---|---|
| `SDK location not found` | Gradle לא מוצא את ה-SDK | פתח פעם אחת דרך `npx cap open android` — הוא כותב את `local.properties` לבד |
| `Unsupported class file major version` | גרסת Java לא נכונה | התקן JDK 21 (שלב 2) |
| האפליקציה נפתחת ומיד נסגרת | קריסה בעלייה | חבר בכבל והרץ `adb logcat -s Capacitor:* chromium:*` כדי לראות את השגיאה |
| מסך לבן / ריק | `dist` לא הועתק | הרץ `npm run build && npx cap sync` ובנה שוב |
| שינויים בקוד לא מופיעים | שכחת sync | `npm run build && npx cap sync` — **תמיד שניהם** |
| רוצה לבדוק לפני בנייה | — | `npm run verify:android` בודק XML והפניות למשאבים בשניות, בלי Gradle |
| רוצה לוודא שה-Java מתקמפל | — | `npm run check:java` מקמפל את קוד הווידג'ט מול פלטפורמת אנדרואיד אמיתית |
| `Could not resolve...` בזמן Gradle sync | אין אינטרנט או חומת אש | ודא חיבור; הבנייה הראשונה חייבת רשת |

## מה עובד בלי אינטרנט (כלומר: כמעט הכל)

האפליקציה **לא צריכה רשת**. כל הנתונים יושבים ב-SQLite על הטלפון.
במצב טיסה אפשר להוסיף, לערוך, למחוק, ולראות את כל הגרפים.

שתי יכולות בלבד משתמשות ברשת, ושתיהן **נכשלות בשקט**:

| מה | בלי רשת |
|---|---|
| מחירי מניות וחיפוש טיקרים | מוצג המחיר האחרון שנשמר. אף פעם לא 0 ואף פעם לא שגיאה |
| תובנות AI | הפיצ'ר פשוט כבוי |

## ייבוא מהבנק

במסכי **הכנסות** ו**הוצאות** יש כפתור **ייבוא מאקסל**. הוא מקבל קובץ
Excel או CSV שהורדת מהבנק או מחברת האשראי.

מה שקורה: האפליקציה מזהה לבד את שורת הכותרות ואת העמודות (תאריך, תיאור,
חובה/זכות או סכום), מציגה **תצוגה מקדימה** של מה שייכנס, ומסמנת תנועות
שכבר קיימות. שום דבר לא נשמר עד שאתה לוחץ על כפתור הייבוא.

- **המיפוי לא נכון?** אפשר לשנות כל עמודה בתפריטים למעלה.
- **ייבאת את אותו קובץ פעמיים?** הכפילויות יסומנו וידולגו אוטומטית.
- **שורות שדולגו?** לחיצה על "שורות דולגו" מראה בדיוק אילו ולמה — לרוב
  זו שורת הסיכום בסוף הדף.

**התאריכים מפוענחים כיום/חודש/שנה**, כמו שהבנקים בישראל מייצאים.

## גיבוי — חשוב

**כל הנתונים על הטלפון בלבד.** ביטלנו בכוונה את הגיבוי האוטומטי של
אנדרואיד ל-Google Drive, כי הדרישה הייתה אפס תלות בענן. המשמעות:
**אם הטלפון הולך — הנתונים הולכים איתו.**

הגיבוי היחיד הוא ידני:

**הגדרות → Snapshot Backups → Export** — מוריד קובץ JSON. שמור אותו
במקום בטוח מדי פעם. באותו מסך יש גם **Import** לשחזור.

## הווידג'ט על מסך הבית

### איך מוסיפים אותו

1. **פתח את האפליקציה פעם אחת** אחרי ההתקנה. עד שזה קורה לווידג'ט אין
   מה להציג והוא יראה "פתח את האפליקציה כדי להתחיל".
2. חזור למסך הבית ולחץ **לחיצה ארוכה** על אזור ריק.
3. בחר **ווידג'טים** (Widgets).
4. גלול עד **Wealth Horizon**. יש שתי מידות:
   - **יתרה** (4x2) — שווי נקי והוצאה מול תקציב
   - **מבט חודשי** (4x4) — בנוסף, שלוש התנועות האחרונות
5. גרור את המידה שאתה רוצה למסך הבית.

לחיצה על הווידג'ט פותחת את האפליקציה.

### איך זה עובד מתחת למכסה

הווידג'ט רץ **בתהליך נפרד** מהאפליקציה ואין לו גישה למסד הנתונים.
במקום שינסה לפתוח משם SQLite — איטי ומסובך — האפליקציה כותבת אחרי כל
שינוי אובייקט זעיר (`snapshot`) ל-SharedPreferences, והווידג'ט רק קורא
אותו. לכן הוא נטען מיידית, **ועובד גם במצב טיסה**.

```
האפליקציה  ──כותבת snapshot──▶  SharedPreferences  ──קורא──▶  הווידג'ט
```

### מתי הוא מתעדכן

**רק כשהנתונים משתנים.** הווידג'ט לא מתעורר מעצמו ולא מעיר את המכשיר,
ולכן הוא לא צורך סוללה כשאתה לא נוגע באפליקציה.

המשמעות: הוא מציג את **שעת העדכון האחרון** ("עודכן 14:32") ולא "לפני X
דקות". זה מכוון — זמן יחסי היה נתקע על "לפני דקה" ונשאר שגוי שעות.

### תקלות

| מה אתה רואה | מה לעשות |
|---|---|
| "פתח את האפליקציה כדי להתחיל" | פתח את האפליקציה, הוסף תנועה או חשבון, חזור למסך הבית |
| הווידג'ט לא מופיע ברשימה | התקנת מחדש? הפעל מחדש את מסך הבית (launcher) או את הטלפון |
| המספרים לא מתעדכנים | הווידג'ט מתעדכן כשהאפליקציה פתוחה ומשנה נתונים. פתח אותה, ערוך משהו, וחזור |
| אין פס תקציב | לא הגדרת תקציבים. הוסף אותם במסך התקציבים |

## עדכון האפליקציה אחרי שינוי בקוד

```bash
npm run build && npx cap sync && cd android && ./gradlew assembleDebug
```

ואז התקן את ה-APK מחדש. `adb install -r` שומר על הנתונים.
